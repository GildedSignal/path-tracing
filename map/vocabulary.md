# His vocabulary

Speak in these words, never invented codes or names (S75, S179). Plain names for work: say what it does, not "step 3" or "pass 4" (S222).

| Word | Means |
|---|---|
| **T** | ticks from the click's server tick to arrival with everything restored; the one currency |
| **the law** | our Rust reproduction of Mojang's game; Mojang's code and the server are **nature and the judge** |
| **word** | a feedback program run from one event to the next; every word takes a **count** (how many times it runs) |
| **gait** | a word that repeats exactly on uniform ground: (word, phase, count) |
| **sentence** | words chained, each ending at an event |
| **program** | a small table from facts of the state (on ground, sprinting …) to inputs (keys, aim, use) |
| **aim** | a yaw from the law's 65,536-entry sine table; an argument, never a key |
| **event** | a tick where a discrete fact changes (landing, wall, crossing a binade, the food guard) |
| **binade** | a range of floating-point values with one exponent; crossing one is an event |
| **certificate** | the claim "this crossing takes k ticks from these entries", valid until its footprint changes |
| **worldtube** | the cells a certificate reads, with their ticks: its region of space-time |
| **footprint** | what a word read and wrote |
| **light cone** | where the bot can reach, and what can reach it; its lower bound is the kit's top speed |
| **bracket** | the lower bound (LB) and the best known T (UB); closed means decided |
| **kit** / **toolkit** | what the bot carries; it changes the space |
| **zone**, **joint**, **set**, **family**, **piece**, **point**, **hold** | the representation's objects (architecture.md section 2) |
| **site**, **label**, **field** | joints close together; T to hubs; T-to-go for one goal |
| **defect** | where the ground stops giving the same answers to the kit's verbs |
| **corridor query** / **presence query** | one question over a worldtube: is anything different, and where first |
| **the slide** | moving a joint inside its set when a neighbour has a smaller T-to-go |
| **generator** | the recurrence and its parameters, stored once; outputs derived when looked at |
| **wormhole** | an edge not bounded by legs: pearl, portal |
| **toll with a debt** | an edit priced in T plus its undo |
| **mission** | a command until the world is restored; a trip is a mission of one |
| **track** | his course from A to B in his world; the **track clock** times it |
| **flight** | the bot playing a plan in his game; the only test that matters |
| **deviation** | expected against seen, per prediction |
| **Fermi floor** | the order-of-magnitude least cost; the **gap** to it is the signal |
| **idiot index** | cost over its floor |
| **SR-71** | seal only what cannot be corrected |
| **ES** | Emergent Space, his engine: worldtubes, certificates, generators, light cones |
| **one mechanism** | no terrain kind gets its own path |
| **the integrator** | the main Claude session: specs, merges, the map |
