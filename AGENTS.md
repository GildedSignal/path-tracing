## Truth

- **Nature and the judge:** Mojang's 26.2 code and the server. **The law** is the generative structure we write to reproduce them (S46): the tick recurrence, words, and the medium.
- **Seal only what can't be corrected (SR-71).** Narrow words (gaps at the limit, clutches) get bit-exact gates, frozen before their first run and never weakened. Everything else is checked by the deviation stream against the server.
- **No job without a consumer.** Every port delta, test and probe names the word, deviation or rung that needs it.
- **Evidence:** measure the build before claiming; Fermi floors for architecture (S45); distributions, never an average alone; anomalies are the most important data; every number in a doc is regenerated by a committed script.

## Rules

- **How many at once.** One Claude sub-agent, plus up to four GPT Terra jobs, four at once only as fresh first prompts (S99; a resumed job runs with fewer), and only one GPT job while Astra runs, in dependency order, never on the same files. GLM has no slot limit (S47).
- **The integrator orchestrates.** It writes specs and prompts, reads verdicts and decides. Builders build, judges judge, runners run.
- **Resuming.** A stopped agent resumes: SendMessage for Claude, a fresh `gpt.ps1` run with a continuation section for GPT. GPT can't write git metadata, so the integrator commits its work with `Built-by:`.
- **Prompts.** Each prompt starts with PRINCIPLES' "goal" and "philosophy" sections, verbatim, followed by its job file `jobs/<id>/prompt.md`, which gives the inputs, the output, the gate and what the job must not touch.
- **Worktrees.** Builders work on `wt/<id>` branches in worktrees on D:. The integrator merges into `main` after the judge passes. `PATHTRACING_ROOT` points every worktree at the one rig, and gates take the rig lock.
- **No new search code.** Capabilities enter as law and toolkit data only. A capability that needs its own search or geometry means the representation is wrong: stop and re-derive it.
- **No patches.** A special case, tolerance, epsilon, retry or per-block branch added to make a check pass signals the wrong representation (ES 19). Write the failure down and re-derive with the integrator.
- **His repeated requests.** A request Julien makes twice becomes a tracked item in HANDOFF with an owner.
- **Jobs that keep stopping.** A job that stops twice on its own failure goes back to the integrator for a new spec.
- **Julien's words.** His turns go verbatim into `docs/reference/`, and the register in PRINCIPLES.md cites them; models never reword them. For a new idea, think and talk with him first, and build when he says so.
- **Tests answer fast** (S49). A test exists to answer one question as fast as possible. A test that tries too much hunts for something that isn't there, or that will turn up later anyway: diminishing returns. Normal tick tests stay; exhaustive sweeps don't. Iteration beats perfection.
- **Run records, merge door, component state** (ES method, S59):
  - Every run (check, gate, bench, flight, lab run) writes a record: inputs for exact replay, each invariant's worst margin, and every refusal. A new worst margin or a refusal goes to the anomaly list in HANDOFF.
  - A merge prints its net lines; growth needs a `Bought:` line in the commit saying what it buys.
  - A component's state comes from facts. A sketch exists only on a branch. A flying component is on main. A load-bearing one has dependents or a frozen gate. A frozen one has a hash in a spec. Investment follows the state.
- **Cleanup once per phase** (S49), as the phase's last step, never in between: delete merged branches, worktrees, build folders, finished job folders, and any check whose result is now a regression test; make the docs true. First move any tool that code still references (oracles, corpora) to `oracles/`, and check `git status --ignored`. Done more often, it's busy work. Done less often, it bloats.
- **Pace.** No time estimates. Progress is the scoreboard: T, cost and scale. Every phase ends in a flight he can use.
- **Publishing.** `GildedSignal/path-tracing` is public (S21). The integrator pushes `main`; builders never push. No secret, password, token or game jar is ever committed.
