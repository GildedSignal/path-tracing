# Lens: look backward from the goal, biggest tool first (and how long momentum remembers)

**Why it matters.** Julien (12 November, S91): words are functions, one per set of conditions, that compound into tools, "shaped in a way that is useful for us not doing some kind of reverse kinetic that is expensive"; "when you look backward from the goal towards you what makes you think to look 3 blocks behind without trying too much ... you start with the biggest one i think it breaks and then you go smallest and smallest"; and "T is conditional on order so blocks don't have intrinsic T cost." Two claims follow and neither is measured. (1) A free arc is invariant under whole-block translation (lane `arc-certificate`, reproduced), so the set of places from which a tool lands on a goal is the tool's own reach table mirrored about the goal: looking backward needs no inversion, only a lookup; and the run-up a takeoff speed needs says how far behind the takeoff to look. (2) Order matters only through the state a bot arrives with, and the law's per-tick multiplier (friction × drag, `engine/law/src/movement.rs` `travel_air`) makes that state forget its past at a rate the ground fixes; beyond that length a place does have a cost of its own, per gait.

**Inputs.** `engine/law`, `engine/words` (programs, gaits, `pieces`, `invent`), his 18 tracks in `engine/world/tests/fixtures/`, `lab/wiki/arc-certificate.md`, `lab/wiki/gait-modulo.md`, `lab/lenses/generative-function.md` (a sister lane; build your own tables by running the law).

**The question.**
1. **Tools as tables.** For each tool the tracks allow (sneak, walk, sprint, jump, sprint-jump, each with and without a 45-degree strafe; add a ceiling variant where a ceiling exists): its reach table (displacement after k ticks, as landing offsets per height change), the takeoff state it needs, and the run-up (ticks and blocks) that reaches that state from rest and from each gait. Order the tools by speed over distance.
2. **Backward lookup.** For each goal platform on each track: mirror each tool's reach table about the goal and list the standable cells it contains whose tube is clear and whose run-up cells exist. Take tools biggest first; when a tool's set is empty, take the next. Recurse from the chosen takeoff toward the start. Certify the resulting sentence by one forward replay in the law. Report per goal: cells examined, tools tried, wall time, whether the replay arrives, and the sentence's T.
3. **Against forward invention.** The same goals by today's forward invention (`pieces` at each state, every program at every aim): cells or pieces examined, wall time, T found. Where the backward sentence is slower than the forward one, say why (a smaller tool chained twice beat the biggest one; a setup cost).
4. **Where the mirror fails.** Cases where the mirrored table says yes and the replay says no (a wall or ceiling met in flight, an edge, a binade boundary), with counts. Each is a tool not yet in the list or a clamp: name it.
5. **How long momentum remembers.** For each ground (stone, ice, blue ice, slime, soul sand, honey) and in the air: start the same program from different entry velocities and count the ticks, and the blocks travelled, until the states are bit-identical (or report that they never are and how the difference shrinks per tick). Compare with the multiplier in the law. Then: for two-jump chains on his tracks, how much does the T of the second jump change with how the first was done (distribution)?
6. **A place's own cost.** Past that memory length, is the cost of crossing a stretch of uniform ground the same whatever came before (per gait)? Measure the largest difference.
