# Map scout (Sonnet 5.5, 16 Nov 2026)

Nothing was downloaded. Every file URL below answered a HEAD request with `200`, `Content-Type: application/zip` and the stated `Content-Length` (converted to MB, 1 MB = 1e6 B). Method note: minecraftmaps.com, CurseForge and Planet Minecraft returned HTTP 403 to every fetch (WebFetch and curl), so their pages could not be read. Every page cited here is the **mapcraft.me mirror** page. It hosts the zips itself (no ad gate, no redirect) and shows the map's version and the author's text. The mirror carries no licence, so "not stated" means the mirror page states none; the original pages were not readable. Nothing was opened inside the zips, so statements about command blocks or datapacks are only what the author's text says. Page base: `https://mapcraft.me/parkour-maps/<slug>`.

Honest gap: the "very long simple movement" extreme is thin. I found no clean human-built sprint-line or ice-road map. The closest are in table 2. Sprint Racer (kart/combat racing, AI opponents, 1.14.4) was rejected.
