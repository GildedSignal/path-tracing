# ES Audit: Do We Respect Emergent Space, or Run the World on Ticks?

## 1. Verdict

- **Where we respect ES:** The ground layer on `main` ([snapshot.rs](file:///C:/Users/PASCAL/Desktop/path%20tracing/engine/world/src/snapshot.rs#L7-L60), [footprint.rs](file:///C:/Users/PASCAL/Desktop/path%20tracing/engine/law/src/footprint.rs#L79-L159), [pattern.rs](file:///C:/Users/PASCAL/Desktop/path%20tracing/engine/law/src/pattern.rs#L268-L342), [class.rs](file:///C:/Users/PASCAL/Desktop/path%20tracing/engine/words/src/class.rs#L25-L104), [gait.rs](file:///C:/Users/PASCAL/Desktop/path%20tracing/engine/words/src/gait.rs#L55-L135)) collapses 30,951 block states into 519 models, records footprints in a 4 KB stack window, caches cell digests by `(model_id, mask, loaded)`, keys classes by the law's own comparison bits, and discovers canonical gait attractors.
- **Where we don't:** The planner on `wt/play` ([search.rs](file:///D:/path-tracing-wt/play/engine/plan/src/search.rs#L285-L451), [polish.rs](file:///D:/path-tracing-wt/play/engine/plan/src/polish.rs#L27-L64), [reach.rs](file:///D:/path-tracing-wt/play/engine/plan/src/reach.rs#L49-L302), [arith.rs](file:///D:/path-tracing-wt/play/engine/plan/src/arith.rs#L32-L124)) and segmenter ([segment.rs](file:///C:/Users/PASCAL/Desktop/path%20tracing/engine/words/src/segment.rs#L79-L111)) still run the world on ticks: cutting segments at every `BodyBlock` crossing (~1.55 ticks), replaying proposals and airborne arcs tick-by-tick through `try_tick`, re-simulating full sentences from tick 0 on every joint slide, and copying ~320-byte `PlayerState` structs plus 624-byte heap bit-vectors per node.
- **What it costs us:** Thinking time adds **4â€“466 server ticks** to $T$ (23.1 s = 462 ticks in `polish::slide` on `straight800`; 180 ms = 3.6 ticks per invocation in `Reach::compile`; 11â€“28 Âµs per expanded edge instead of ~0.7 Âµs), cell-keyed backward reach stalls `fences`, `fencemaze`, and `redfakemaze`, and ~2.5 KB/node memory traffic balloons a single search past 1.5 GB RAM instead of 24 bytes/bot for $10^4$ bots.

## 4. The GPU Paragraph
