## Decisions on the seven points

1. **The frozen gate can fail: yes.** Turning a hold into a clamp, dropping the cuts and shifting an exit by 1 ulp each turn it red. The oracle is a native run of the law's tick (`tick_with_collision`, reached through `law::contact::tick`), and exits are compared bit-for-bit with the resulting states. It is not the family code. Two weaknesses are in findings 2 and 3.
2. **The old reds are superseded, not weakened.** `engine/plan/tests/u2b/pieces.rs` asserts the event-only object: the pin is a `u128::MAX` marker inside the event signature, pin endpoints are equal (`pin has undeclared differences`), and the counts are the S188 ones (gap 5, step 8). The first failure is `pieces.rs:65`, a partition mismatch on exactly the pin marker (left has the marker, right does not). Nothing that passes now depends on `pieces.rs`; only `verify.ps1` and the independent workspace sweep skip it by name. It is unedited (hash checked by `review.ps1`).
3. **Zero copies and zero allocations are counted, not asserted by fiat: yes.** The state type counts every `Clone` (feature `count-state-copies`, enabled through the dev-dependency in `plan/Cargo.toml`). A counting global allocator counts alloc, alloc_zeroed and realloc. Both negative controls above are caught, and `u2b_counters_detect_work` pins the counters themselves. Limit: only `Clone` is counted, not a by-value move or a bit copy of a `PlayerState`.
4. **The stop on B is looked up in a warm solve: yes, with a caveat.** `terminal.rs` builds a face-preimage table once per key (floor label, gait, phase, chart, y, target y). `JointStore::terminal` then reads it (`terminal_lookups` rises, `terminal_builds` stays flat; asserted in `u2_terminal_joint_reuses_face_preimages`). No control search is left per goal. What remains per goal is arithmetic, not search over controls: `events::horizon`, `first_cross`, `first_touch_readout`, `lattice::counts`, and a linear scan of `Set::rows` in `lookup`. A goal near a binade edge gets its own chart (`edge:cell`) and so a table build; this is bounded but is not free.
5. **One mechanism: not clean.** See finding 1. The tolerance question is clean: `plan/src` has no epsilon, retry or `1e-N` constant. `CONTACT_ZERO` is 1.0e-7, equal to the literals the law already uses (`shapes.rs:399`, `movement.rs:614`). It is a duplicate, not a new number (finding 5). The aim does not enter any entry key: `pattern.rs:318` zeroes yaw, pitch and input in `start_bits`, and `u2_point_route_entry_has_no_aim_memory` and `u2_point_wave_joins_aim_aliases_with_numeric_guards` show it. A one-ulp velocity change is still distinguished.
6. **Timings.** `U2B_WARM` (57 / 69 / 92 µs median in the integrator sweep) times the public `plan::solve` 100 times back-to-back on one store, so caches are hot, with the allocator and copy counters wrapped around each call. `U1_SOLVE` warm (112 / 124 / 167 µs) is the core's test (`zones_prereqs/u1.rs:55-75`): each of its warm samples follows a fresh cold solve of about 190 ms on an empty store, so its caches are cold, and it times the same call. Neither is an extra work difference of 2x in the code; it is mostly cache state. The warm million line the plan's gate means (a click after the store is learned, other work in between) is nearer `U1_SOLVE`; `U2B_WARM` is the hot best case. Both are about 11x to 25x the ~5 µs floor. Remaining, from Astra's profile (µs, median, axis / z / oblique): entry 3.3 / 4.2 / 4.9, bearing 10.5 / 10.5 / 3.0, inverse 30.8 / 42.0 / 64.3, output 12.0 / 12.1 / 24.1. The inverse (phase enumeration, readouts, run reconstruction, linear row scan) and the output (envelope and binade walk) are the cost. Axis bearing uses the floor-sum fallback (30 quotient queries). The plan row's "59 and 95 µs" are from Astra's earlier run; the final record is 57.2 / 69.4 / 97.5.
7. **Merge risk.** The recurrence is unchanged: only observation was added. `movement.rs`: `collide_in_world` returns a `contact::Pass` and `collide` calls `report.report(world)`; the collision arithmetic, visit order and early zeroing are untouched (the same `d.abs()<1.0e-7` tests, with a recorded Hold). `shapes.rs`: `collide_report` records Clamp/Hold and returns the same distance; `face_comparisons` is new and read-only. New `contact.rs` (opt-in `tick` wrapper). `world.rs`: `observe_axis_contact` hook (default no-op) and derives. `footprint.rs`: forwards the hook. `state.rs`: `Clone` becomes a manual impl, same fields, with a feature-gated counter. `state_reads.rs`: `NON_MONOTONE_FIELDS`. `codec.rs` / `codec_state.rs`: allocation-free keys and a legs cache (`model_same` compares every `Block` field bit-exactly; a field added to `Block` is a compile error because of the destructuring, which is good). `pattern.rs`: `start_bits` now zeroes aim and input, which changes the legacy pattern key, not the law. `LAW_HASH` changes with the sources, so the replay record (KT10 line) carries a new hash.
