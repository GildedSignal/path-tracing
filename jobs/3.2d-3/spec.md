## 2. R1: one codec and the label that keys the store
One interner owns ClassId and LabelId. A class is intern(verb/kit query signature, role/mask, canonical answer bytes); digest lookup ALWAYS compares bytes before returning an existing ID. Store records are typed; a raw digest cannot certify sameness.
The codec replaces independent encoding/equality in footprints, pattern keys, words::class/ProposalTable and law_digest, including presence. Old APIs may be compatibility wrappers over it; there is no fifth role encoding. State answers and cell answers use this same schema, with source address/tick kept outside class identity.
Keep fine block-state identity plus registry hash in the source, not only the 518-model legs projection. Each kit selects a projection table from fine IDs/query contexts to class IDs. Changing kit swaps this projection, not a second terrain copy or a full reclassification walk.
Legs projection retains the four roles: Support02 and Support05 use Hooks|Loaded; BodyFeet uses Shape|Fluid|Hooks|Loaded; Inside uses Fluid|Hooks|Loaded. Masks come from footprint::Query; context-dependent shapes and coefficients remain exact.
Omit world_hook from legs answers; omit air only when Inside::None and stuck_multiplier is absent; omit fluid_flow only when fluid is empty. Local has_inside_effects is a certified tube query, so a distant cobweb does not break flower/air equivalence. Actual effect obligations remain separate.
Break projection includes the existing verb's hardness/tool-time/harvest and drop-generator answers, including silk-touch context; place includes replaceability/face/legality and replacement/restoration debt answers. Use native/ported query data, not a sampled drop or a flower-name rule.
Unported break/place queries return Unknown with fine identity retained; they cannot borrow a legs equality or create an executable capability. Tests split classes where native verb answers differ; do not assume every flower blocks placement. Leg-equivalent stone/grass may differ to a silk-touch kit.
A footprint is (cell or state source, tick, verb-role/mask, answer ID); pattern/form keys and proposal classes are ordered references to these same IDs. Class proposes; exact state/proof still decides. A new law/read field invalidates the schema until assigned.
LabelId = intern(law/schema, body/kit projection, support-class tuple, medium-class tuple). This is the zone label and EXACTLY the generator store's outer key (U3), not a parallel tuple/digest map. It needs no R3 zone partition.
Support/medium contain their kit-relative verb answers and legs roles; a word declares its read subset. Different finer kit labels may reference the SAME legs kernel when its coefficients/read answers match. Yaw is an argument, never an outer store key.
Section role planes remain the existing leaf presence interface: AllZero/AllOne/Words with complete/loaded masks; absent data is Unknown. Query masked planes before locating exceptions, single-thread SIMD. No whole-section epoch invalidates unrelated queried bits.
Certificates bind exact requested role bits/cells, tick/schedule reads and source coverage; the tube is derived from body/pose/apex/support offsets and real collision shapes, never widened by a chosen amount. Check the full 4D worldtube ONCE when made, using the existing arc/read certificate on its qualified domain; reuse without tick scans. Edits notify its reverse footprint index, compare recorded contents at the recorded ticks, and recheck only affected claims. Same-content/unrelated edits preserve it; outside-halo reads refuse. Include the un-evented one-axis wall release and sneak back-off reads.
For a homogeneous-source certificate use its label directly; do not scan every section along a million-block line. Varied terrain uses near-source leaf data and the rolling horizon; R3 will later reduce these same leaves, not build a competing index.

## 3. R2: one store, memoised transients, exact event maps
GeneratorStore[LabelId].word(WordId) returns one immutable kernel: recurrence/phase contract, transient jump summaries, cycle maps, read/resource summaries, law guards and proof scope. No start/goal/track/absolute-coordinate answer is cached.
Replace arith::Cycle/free-arc ownership, reach.rs hop/path tables, gait.rs's private memo and plain.rs's fold with adapters to this store (D3). Delete reach.rs's f64 sin/cos rotations; evaluated law table coefficients are the only directional dynamics.
Motion recurrence key = exact read-before-write motor bits, phase and bound recurrence operands. Position/absolute t are affine anchors; supporting addresses are represented through the certified read roles; resource numeric values are retained separately and enter motion through proved law guards, never fed substitutions.
Bound arguments, including the law's direction coefficients, belong to a parameterised memo entry; this is not another per-heading reach store. A word's internal phase never turns its floor label into a new air table key.
T1 prepares the transient ONCE under that recurrence key, retaining its exact ending motor state, duration, resource/read summaries and compiled prefix/jump maps. Applying it uses the actual anchor and binade, not a translated sample or ~274 law calls on every click.
Preparation/qualification may run native ticks off-command; runtime queries may not. Publish exact argument/seed/binade coverage and preparation cost. The any-bearing gate requires coverage of the law's yaw-index domain and relevant entry phases, not a cache warmed by track answers; missing coverage is reported, never a tick-loop fallback.
U1 is the fold rule: binade exponent/sign/zero mode, food_level, sprint-allowed, loaded, zone-label boundary and yaw switch are event metadata under vocabulary §4. Merge their known deadlines; retain periodic phase/contact series compressed. Events do not reset the word's documented clock or force a new decision.
Between these events use exact integer maps of the law's rounded additions, not p+q*sum(d) in real arithmetic. A phase displacement is the actual moved operand before movement.rs's position addition, not p_after-p_before or wanted motion when clipped.
For a fixed binary64 binade with spacing U, write p=mU and the phase operand d/U=N+r by exact dyadic division. The added integer is N if r<1/2, N+1 if r>1/2, and N+((m+N) mod 2) at an exact half. Retain signed-zero/subnormal/boundary ownership explicitly.
Compose the fixed word's phase maps on integer mantissa and parity. The finite parity map has a prefix/cycle; quotient/remainder over that finite graph advances q cycles exactly. Finite-state size derives from the parity bits, not a chosen depth/grid/tolerance.
The next exponent/clamp event is the minimum over stored phase comparisons, obtained by integer ceil/floor division of those affine maps; do not step toward the boundary. Apply the exact boundary operation and continue in the next region. Phase summaries may be queried, never expanded q times.
Transient prefixes use the same compiled maps and indexed law-comparison boundaries. Remainders/first detector touch come from inverse integer intervals of the shared Goal::touched predicate and stored vertical-phase eligibility, not simulation of the last few ticks.
T2 must prove these maps, domain guards and exact endpoint ownership; all source comparisons/rounding rules are recorded. No empirical corner enclosure, epsilon, unproved translation or partial-endpoint equality promotes a Yes.
Any bearing uses TWO adjacent actual law-direction vectors, not only axes or nearest yaw. Bracket the requested direction by exact cross-products of the law-table vectors; canonical ties use the lowest native index. Include both start transient and the yaw-change transient from the real carried state.
For each stored phase/event regime solve the exact two-integer lattice lo<=E+q1*D_i+q2*D_(i+1)<=hi, q1,q2>=0, after pulling the detector comparisons through the integer maps. E includes the memoised transients/phase offsets; do not rotate velocity instantly or ignore binade changes.
T3's arithmetic routine intersects the corresponding ceil/floor integer intervals, selecting minimum tick cost then canonical counts. Use Euclidean quotient/floor-sum interval arithmetic over exact dyadic integers, not a q-by-q loop, yaw sweep, graph/LP/SMT solver or candidate replay. Its construction/proof is a prerequisite artifact, not an open choice for the integration builder.
All count domains come from law/detector/event comparisons. T3 must bound work by event regimes and native operand bits and reject an implementation whose count enumeration grows with distance. Arithmetic overflow/unsupported maps are Unknown; the required gate instances must not take that exit.
A decision is a committed word/argument/stop, counted at switches; evaluations are reported separately. Equal T uses fixed lowest-index/canonical-count/FIFO order at zero extra T, never clearance descent on a plateau. Width is a second key only at zero width (SR-71); a saddle is a switch where word costs change by at least one tick.
The peaceful oblique plain sentence has five committed choices: word, yaw1, first count/switch, yaw2, stop. Axis/degenerate cases elide unused choices; never force a second yaw or count hidden evaluations as free decisions.
